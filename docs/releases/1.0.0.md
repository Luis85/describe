# Describe 1.0.0

Create structured Markdown descriptions for files and folders without renaming or modifying the originals. Requires Obsidian 1.13.7 or newer.

## Included

Describe! is available from an item's context menu and from commands for the current file or an item picker. The modal captures a name, full Markdown description, tags, category, optional hex color and aliases. Notes contain ItemDescription frontmatter, an 80-code-point summary and a source wikilink. Image, audio and video sources use embed syntax.

Choose a saved per-extension destination, the source's folder, or a configurable descriptions subfolder. First-use routes are remembered after successful creation. Existing notes are preserved with numbered filenames. Native declarative settings expose storage preferences and known file types.

The interface supports keyboard entry, field-specific errors, draft preservation after write failures, saving feedback and narrow layouts. The runtime uses public Obsidian APIs and has no account, network service, telemetry or desktop-only dependency.

## Installation and limits

Install through Community plugins after directory approval, or place main.js, manifest.json and styles.css in your vault's plugin directory and enable Describe. Review SHA256SUMS before manual installation; release-metadata.json identifies the source commit and package digest.

Aliases and color belong to the new description note, not the original item. Folder wikilinks record a reference and do not guarantee native folder navigation. Media playback depends on the operating system and codec. The plugin does not update older descriptions when a source moves. Hidden/configuration items and the vault root are excluded. Keep a backup before trying a new plugin in an important vault.
